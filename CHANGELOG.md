# Changelog

All notable changes are documented here. The format follows Keep a Changelog and semantic versioning.

## [1.0.0] — 2026-09-15

### Added

- Deterministic RK4 plant simulator and sampled parallel PIDF controller.
- Eight plant model families, dead-time buffer, sensor and actuator non-idealities.
- Main lab with transport controls, synchronized engineering charts, live internals, metrics, and exports.
- FOPDT and ultimate-cycle tuning methods with eligibility rules and four-way comparison.
- Simulated relay-feedback experiment.
- PID term, time-constant, and second-order teaching explorers.
- Source-audited research, numerical, tuning, validation, contributor, and citation documentation.
- Responsive light/dark interface, keyboard shortcuts, reduced motion, and GitHub Pages deployment workflow.
