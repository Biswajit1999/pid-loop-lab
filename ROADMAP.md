# PID Loop Lab roadmap

The roadmap is organized around scientific trust, learning value, and reuse.

## v1.2 — Missions and discoverability

- Scored PID missions with reproducible starting configurations
- Deterministic response explanations
- Local experiment notebook and shareable result cards
- Mobile quick-tune workflow
- Searchable learning guides, sitemap, structured data, and PWA metadata
- Contributor templates and community documentation

## Next

- More mission packs for motor, thermal, and mechanical plants
- Side-by-side saved-run comparison and annotations
- Embeddable read-only experiment mode for course material
- Keyboard-accessible chart data cursor
- Additional validated identification and frequency-domain tools
- Translations maintained by native-speaking contributors

## Contribution priorities

Look for issues labelled `good first issue`, `plant model`, `learning content`, or `validation`. New numerical methods should include references, assumptions, tests, and documented limitations.
